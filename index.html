🗓️ Google Calendar Setup

One-time setup per device. You need a Google Cloud OAuth 2.0 Client ID with the Calendar API enabled.

  1. Go to console.cloud.google.com → APIs & Services → Credentials
  2. Enable Google Calendar API for your project
  3. Create an OAuth 2.0 Client ID (Web application type)
  4. Add your GitHub Pages URL to Authorised JavaScript origins
    e.g. https://yourusername.github.io
  5. Copy the Client ID (ends in .apps.googleusercontent.com) and paste below

☁️ GitHub Gist Sync

Your plan and recipes are saved to a private GitHub Gist and synced automatically every 5 minutes and on demand. One-time setup per device.

  1. Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate a token with only gist scope ticked → copy it
  3. Go to gist.github.com → New secret Gist → filename plan-data.json, content {} → Create
  4. Copy the Gist ID from the URL (the long hex string at the end)
